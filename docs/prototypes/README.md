# UI prototypes

Static HTML mock-ups that specify how the game's screens look and behave. They are
reference specs, not shipped code: open them in a browser to see the intended design.
`docs/` is in `.vercelignore`, so none of these files is deployed.

| File | What it is | Issue |
| --- | --- | --- |
| `on-call-trace-play.html` | Spans and Traces "Build it" widget, v9 (the redesign) | #146 (merged) |
| `incident-board.html` | "Who is talking" incident board, v2 | #143 (approved) |
| `lesson.html` | Lesson text styles; variant C is the glow lesson card | #158 |
| `on-call-look-study.html` | Look-and-feel study: globe, palette, type, layout | epic #152 |

Builders follow these prototypes unless an issue records an owner decision that differs.
