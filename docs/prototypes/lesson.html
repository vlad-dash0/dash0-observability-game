Lesson text: three styles

Level 0.1 as it would render, with the choice cards styled as today so the contrast is visible. All three use 18px, weight 400, line-height 1.6 and slightly softer-than-white text. Follows the system theme; light tokens included.

AEditorial

Removes the card entirely; the lesson is open text with a small amber LESSON eyebrow.

Monitoring answers the known questions. Observability is being able to answer the new ones from the telemetry your system already sends, without shipping new code.

What makes the second kind answerable?

More alerts
Keeping data for longer
Telemetry with many attributes you can slice after the fact
More dashboards
Longer example with a code chip

Every span carries a service.name attribute, so you can group a slow request by the service that handled it, then drop to the single trace that explains the delay.

.bubble{
  background:none;border:0;border-radius:0;padding:0;
  font-size:18px;line-height:1.6;font-weight:400;
  color:var(--color-lesson); /* new: dark #d9d6d1, light #3a3836 */
  margin-bottom:24px;
}
.bubble::before{
  content:"LESSON";display:block;margin-bottom:10px;
  font:400 11px/1 var(--font-mono);letter-spacing:.14em;
  color:var(--color-lesson-eyebrow); /* dark rgba(243,179,95,.78), light #a8650f */
}
.bubble code{
  font-family:var(--font-mono);font-size:.8em;
  background:var(--color-code-bg);color:var(--color-lesson-code); /* dark #f3b35f, light #7a4a08 */
  border-radius:6px;padding:2px 6px;
}
